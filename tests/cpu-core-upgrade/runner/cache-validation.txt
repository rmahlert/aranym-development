there are no resident cache lines, pending copyback writes, prefetch-line cache,

cache behavior or timing. CACR/transparent cache attributes remain architectural
control bookkeeping. A future cached/JIT backend must implement invalidation,
dirty-line pushes, ordering and callback faults before reusing this adapter.
