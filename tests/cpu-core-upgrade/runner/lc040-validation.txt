LC040 absent-FPU probe stage
==========================
Source remains WinUAE d82bc2549f27943d11dc59482d5388daf1c0f337.
No production CPU, configure setting, installed emulator or guest is changed.

The explicit --lc040-probes profile enables 16 additional real generated
FSAVE/FRESTORE/FBcc families. Real fpp.cpp no-FPU helpers are extracted with
hashes. FSAVE/FRESTORE are exact source prefixes through fault_if_no_fpu;
active-FPU tails fail closed, and prefix hashes document this restriction.
FPUEMU is enabled for these bodies so a preprocessor exclusion cannot turn
an instruction into a successful no-op. Arithmetic FPU instructions remain
excluded, and this is not complete LC040 instruction coverage.
