Physical accesses invoke genuine matcher using effective access FC and whether
it is an instruction fetch or operand access. MOVES-selected instruction FCs
remain converted to data references per the already-tested040 bus contract.
Derived enable flags update on genuine MOVEC and architectural snapshot import;
reset clears them. Cache attributes are computed, not a modeled hardware cache.

The execution profile allows ONLY unprotected transparent regions with paged
translation disabled. Any enabled protected TTR stops before the next guest
fetch/callback, even if a particular access would not match. This deliberately
coarse unsupported gate avoids ignoring protection or exposing an RMW device
read before a still-unimplemented protected-access fault/format7 continuation.
It is not a claim of implemented protected-TTR exception behavior. TCR E still
stops before further execution. No page-table lookup/ATC or hidden retries.
