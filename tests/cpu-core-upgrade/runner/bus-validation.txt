Host::bus is optional and Host::bus_opaque belongs to its caller. BusRequest
contains kind(Fetch/Read/Write), full32-bit guest address, width, effective
function code, optional selected alternate FC and transfer type. Value is
big-endian architectural numeric data; callbacks own any byte-layout mapping.
One callback per source-model access, no implicit pre-read/retry/splitting.
false means the access did not complete; a callback must not perform the
rejected operation's side effect. This contract cannot undo an external device
that violates it. Host exceptions may not escape an eventual C/platform bridge
without translation; no such production bridge is implemented here.

Real MOVES source transient ismoves_nommu clears on normal return. Because
source helpers do not clear it on a host unwind, the runner explicitly clears
it in its typed-exit catch. This host-boundary adjustment is documented and
tested; source instruction/helper bodies are unchanged. Reset clears it too.

This is not an Atari MMIO implementation. Actual ARAnyM RAM/ROM protection,
accepted host-window address fixes, hardware devices and exception transport
still need an adapter. Failed accesses remain terminal/reset-latched until
format7 delivery/restart/writebacks are real. Callback bus does not establish
MMU, activeFPU, cache/timing, IRQcontroller, NatFeat/EmulOp or guest bootability.
