Portable integer-helper expansion
=================================
Same immutable WinUAE d82bc2549f27943d11dc59482d5388daf1c0f337.

Imports are mechanically extracted whole pinned newcpu_common.cpp functions:
get_bitfield/put_bitfield, divbyzero_special, setdivuflags/setdivsflags,
setchkundefinedflags/chk2_sub_wrap/setchk2undefinedflags, long division
zero/overflow helpers, m68k_divl/m68k_mull. Exact ExceptionL/op_unimpl from
newcpu.cpp complete the source closure. CPU model is fixed040, so060-only
unimplemented multiply/divide paths cannot fire. No handwritten replacement
instruction body, overflow normalization or post-comparison waiver is used.
UVAL64 is the ordinary host-width constant macro corresponding to sysdeps.h.

72815 assertions pass normal and ASan/UBSan builds:
- Every width1..32 and signed offset-17..39 for all8 memory bitfield operations;
  independent per-bit extraction/update checks every RAM byte, destination,
  flags and preserved X/source/address registers. Dynamic widths include
  zero/full32/overflowed register encodings. Five-byte long+byte read/write
  ordering is checked; second-read fault prevents writes and latches retry.
- Signed/unsigned wordDIV boundary products and all32 initial CCR encodings:
  zero, overflow, independent quotient/remainder and register preservation.
- Signed/unsigned32/64-bit MUL/DIV using independent128-bit host oracle,
  negative remainder signs, INT64_MIN/-1, overflow, zero, aliased destination
  ordering, flags and source preservation.
- CHK negative/out-of-range/equal values with allCCR; CHK2/CMP2 ordinary and
  wrapped intervals; real divide-zero exception creates format2 and actual
  generated RTE restores nextPC and stack.

Undefined040 CHK/DIV flag expectations explicitly test the pinned model's
documented helper contract, not a new hardware-accuracy claim. Memory operation
ordering is the selected fast040 model contract, not transistor/cache timing.
The --negative-bitfield control deliberately corrupts the expected register;
only that exact assertion failure returns1, unrelated errors return2.

No production build setting/core, cache implementation, MMU/FPU arithmetic,
access-error continuation or Atari bus has been added. Remaining missing helper
inventory is machine-generated: cache-maintenance20, alternate-function-code
MOVES21, MMU15, active-FPU24 and RESET1 families. Those need honest adapters
before optional emulator integration. Real format7 restart remains a gate.
