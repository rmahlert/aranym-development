Experimental original FPU backend bridge, 2026-11-08
===================================================
This is the existing ARAnyM IEEE FPU engine, NOT a port of current WinUAE's
arithmetic FPU. The modern integer interpreter remains pinned to WinUAE
 d82bc2549f27943d11dc59482d5388daf1c0f337; private/native backend lineage is
 c762046250551840d9c0f32c607713f71a05afa3 plus accepted b6735e93 baseline.
Its source authorship/GPL headers remain untouched.

Default runtime profile remains truthful integer/LC040 absent-FPU probes.
Set ARANYM_MODERN040_LEGACY_FPU=1 explicitly to select the original IEEE FPU.
EmuTOS executes real FRESTORE/FNOP/FSAVE and derives its own FPU cookie; no
cookie is injected. Only this IEEE backend/native68040 profile is accepted.

The coherent modern decoder classifies40 real generated FPU families by their
actual helper calls. It suspends after one numeric-BE opcode fetch, before
extension/operand access, returning original PC. The frontend calls the REAL
original generated handler from its resolved table once, using the same native
fetch encoding as that table. Extensions/data go through original memory
helpers; FP0-FP7/FPCR/FPSR/FPIAR remain owned by the original engine. No struct
cast or synthesized instruction body is used. Integer state/flags/banks are
copied explicitly; advanced/branched PC is imported with original instruction
PC retained. Completion does not replay/refetch/count the instruction again.

Native adapter compiler DEFINES now come verbatim from the native Makefile,
including flag ABI, opcode fetch encoding and FPU type, and are recorded in
modern040-build.json. config.h feature probes alone do not establish this ABI.
An original FPU helper's synchronous Exception enters genuine modern frames;
FTRAPT tests independently verify format2 SR/nextPC/vector/instruction-address
and real RTE. Native FPU operand faults/restarts, enabled FPCR arithmetic traps
and traced FPU instruction boundaries fail closed. This does not establish all
FPU exceptional values/accuracy, paging, format7 continuation or native JIT.

m68k-atari-mint-gcc -m68000 -msoft-float guest-c.o guest-asm.o -o FPBRIDGE.PRG
