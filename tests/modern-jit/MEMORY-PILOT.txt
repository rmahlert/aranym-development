Default-off checked scalar MOVE pilot
====================================

Base Linux qualification remains commitfe250a4a on modern-jit-harness. This
separate modern-jit-memory-pilot branch adds only an explicitly enabled helper
experiment. Set ARANYM_UPSTREAM_JIT_CHECKED_MOVE=1 to admit MOVE.B/W/L between
Dn and (An) in TT-RAM code. ROM instructions keep genuine interpreter dispatch.
With the variable absent, the qualified register/control-only table is retained.

Actual imported functions used
-----------------------------
The unchanged d82 generated ff/nf instruction families1010/3010/2010 load and
1080/3080/2080 store implement EA, register and CCR semantics. The upstream
call_r_11, call_r_02, flush_all, prepare_for_call_1 and prepare_for_call_2 bodies
are now compiled for this native profile too. Six small native adapter functions
perform one operation through the same existing checked physical/HW bus adapter.
These are bus/ABI glue, not handwritten replacement m68k instruction bodies.

The upstream x86-64 direct-memory path assumes a loaded/reserved R15 natmem
base. This pilot never enters it. Helper function pointers fit the explicit
Linux no-PIE image; the emitter verifies32-bit scratch-pointer compatibility.
Byte/word/long helper returns are numeric guest-endian values, so no extra swap
is performed. Upstream call preparation preserves live architectural values and
CCR/X across actual helper calls. It is intentionally conservative.

Admission/failure contract
--------------------------
Only one explicit memory operand is admitted: Dn<->(An). MOVEA, absolute/indexed/
displacement/PC-relative modes, postincrement/predecrement, implicit stack ops,
MOVEM and read-modify-write instructions remain interpreter operations. Tracing
still routes to the genuine interpreter. No MMU, generic access-fault restart,
unaligned/cross-region MMIO or broad device-protocol acceptance is claimed.

A failed helper transfer stops with an explicit unsupported diagnostic and host
exit3. It does NOT deliver a qualified architectural fault frame, replay the
transfer or resume the guest. The reported instruction/address/size identify the
boundary; full register diagnostic synchronization on a fault is not asserted.
This limitation keeps the pilot default-off even after the positive gates below.

Read-sensitive fixture and independent checks
---------------------------------------------
ARANYM_UPSTREAM_JIT_SIDE_EFFECT_FIXTURE=1 enables a synthetic device only in the
owned regression profile. Both genuine modern interpreter and emitted helper
arms share this same bus. Every read at00fef000 increments a counter and returns
a changing value; writes increment their own count and preserve their actual
width/value. Separate status registers let the ordinary guest observe counts.
One uncompleted transfer address increments a fault-attempt count and returns
failure. No real Atari device, owner image or external process is inspected.

Guest checked-move.{c,S} verifies512 reads and512 writes for EACH B/W/L phase,
all32 initial CCR states, partial-register data/endian behavior, D/A sentinels and
A7. It passes identically with helpers enabled, helpers disabled and JIT disabled.
Wrong expected count is rejected by the real guest. After warming the translated
load, an intentionally failed transfer exits3 with exactly one observed attempt
and zero replay. run-bootstrap.py records the actual controls and requires a
translated-memory witness where appropriate. Access counts come from a separate
bus observation and guest expectation, not emitted-code counts alone.

Actual full Linux system gate
-----------------------------
The identical closed c1 MiNT/fVDI fixture passes with the helper pilot off AND on,
with the synthetic device disabled. Both reach AES, resident fVDI/GDOS,32 planes,
three vector fonts/ID163d, metrics/extent/real text output and guest shutdown0.
The enabled arm actually executes3,370,695 translated memory instructions.
Memory-stage-validation.json stores exact binaries/input/log hashes and results.
This is scoped Linux qualification, not Windows/HighWire/restart or a speed claim.

Build ordinary guest fixtures with build-fixtures.py. CHECKMEM is positive;
MEMNEG uses wrong count+1; MEMFAULT deliberately requests the uncompleted
transfer. run-system.py --jit --checked-move enables the actual-device system
arm; by default it clears all synthetic-device/helper environment controls.
No installed build, default product setting, public branch or release changes.
