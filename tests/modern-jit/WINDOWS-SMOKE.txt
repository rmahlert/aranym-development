Private Windows modern JIT smoke packet -- review before use
==========================================================

This packet is separate from the current Windows HighWire matrix and guard.
Root coordinates any later launch after that work. Nothing in this packet
updates an installed emulator. No target was executed during packaging.

Candidate: frozen f3eac0a6 PE, functional source fe250a4a, upstream d82bc254.
The separate default-off scalar-memory pilot is EXCLUDED. Static import closure
and matching library/license files are included. Static checks are not Windows
ABI or runtime acceptance. Source identity and every file hash are recorded.
The manifest detects accidental changes; it is not a digital signature.

Prerequisites, supplied separately by root from the CLOSED accepted c1 fixture:
  prepared.img
  emutos-aranym.img
  starting-nvram.bin
  host/FONTS/DVSANS.TTF
  host/FONTS/LIBMONO.TTF
  host/FONTS/LIBSANS.TTF
SEEDS.json gives exact hashes. No ROM, font, guest image, private TT68K material
or repository/history bundle is included. Do not substitute your working image.
Close all programs using the seeds. Run refuses a seed with an open handle.

Windows PowerShell 5.1, native x64 Windows, one process at a time:
  powershell.exe -NoProfile -File .\windows-smoke.ps1 -Mode Prepare -SeedRoot "D:\closed-c1-seeds"
Prepare hashes the supplied seeds and creates only configs/plan in a new unique
user-folder work directory. It does NOT copy disks or start an emulator. Inspect
the two generated configs, plan and frozen manifest before a separate smoke.
PowerShell policy is respected; no bypass, unblock or downloaded-code evaluation
is requested. Parser review on Windows is still required before the first Run.

Later, only when root schedules this separate smoke, use the exact printed:
  powershell.exe -NoProfile -File .\windows-smoke.ps1 -Mode Run -Plan "C:\Users\...\aranym-modern-jit-smoke-...\plan.json"
Run validates packet/plan/config hashes and creates a one-shot run marker. It
refuses ANY existing native user profile aranym-upstream-jit-experimental.
That compiled profile remains separate from normal aranym. It never rewrites
USERPROFILE or HOME. Existing experimental work must be inspected/archived by
its owner before a new plan; no automatic cleanup, reuse or retries occur.

Each arm gets a fresh exclusively-read verified disk, ROM, three fonts and NVRAM
seed. The same NVRAM is reset before each arm, only into the owned experimental
profile. The first arm is JIT-off, then JIT-on only if off passes. Configs are
otherwise identical:64MiB,no MMU,FixedMemoryOffset60000000,JITFPUoff,ETHoff,
audiooff,redirectionon,hostcursoroff. Only arm-local host H: is exposed.
ARANYM_MODERN040_LEGACY_FPU=1 explicitly enables the original IEEE host-service
boundary required by this hard-FPU fixture in BOTH arms. It is not a new FPU
engine. ARANYM_UPSTREAM_JIT_DIAGNOSTICS=1 records actual translated execution.
Other inherited ARANYM_* and SDL_* experiment variables are removed only in
the child environment; the shell environment is not changed.

The wrapper starts only the exact frozen PE with the owned config and captures
stdout/stderr separately.120s default deadline; timeout stops only its own
process. It keeps every artifact and stops after a failed arm. Failures before
result.json still retain run-started/configs/copied inputs. Do not retry blindly.
Send the whole new work directory's plan/log/result/config files back to root;
guest disks/fonts/ROM are not needed in the return packet.

Pass requires exit0, exact c1 fVDI2be9839adc banner, resident cookie/GDOS/32planes,
three expected fonts/ID163d/metrics/extent/actual VDI text call and guest real
GEMDOS Shutdown(0). JIT-on additionally requires nonzero actual translated and
TT-RAM witness counts. One pass establishes only this owned64MiB Windows c1
boot/font/shutdown smoke. IRQ/trace/invalidations/ABI stress, HighWire, other
profiles, Windows allocation reliability and performance remain separate gates.
Elapsed time is diagnostic; this protocol makes no performance claim.

COPYING.ARAnyM, COPYING.WinUAE and dependent library/runtime notices are under
licenses/. The private packet's complete corresponding experimental source and
local bundles remain with root, identified by SOURCE-IDENTITY.json. Do not
publish this binary packet as a release without root's source/release review.
