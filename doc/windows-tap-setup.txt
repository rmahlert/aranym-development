Standalone TAP setup on Windows
===============================

The optional shared Atari TAP setup kit installs the signed TAP-Windows6
driver directly. The OpenVPN application is not required. Each emulator
gets its own adapter; existing adapters are never selected by friendly
name alone. If another TAP driver version is already installed, setup
stops instead of replacing that shared driver.

When this kit is included, use Start menu > ARAnyM > Network adapter setup,
choose ARAnyM (or Both for Shinogi too), and approve the administrator prompt.
In ARAnyM Network settings, select the TAP/bridge mode when a LAN bridge
has been configured. Empty/default tap0 then uses the exact owned adapter
recorded by setup; explicit custom Tunnel names/GUIDs retain precedence.
SLIRP remains the Internet-only default and works over Wi-Fi without TAP.

An adapter alone does not establish Wi-Fi LAN connectivity. That requires
validation on the real Windows Wi-Fi driver and access point. The kit's
Collect-WiFi-LAN.cmd produces a private read-only preflight report and does
not change networking. Do not enable an unverified Wi-Fi bridge for normal use.
Each simultaneously running TAP guest needs its own adapter. Two independent
managed bridges cannot both own the same physical Wi-Fi/Ethernet adapter.

Packagers can include a verified kit and matching basename .sha256 with:

    ATARI_TAP_SETUP_ZIP=/path/Atari-TAP-Setup-<label>.zip \
      tools/build-windows-dist.sh /path/to/windows-build

The staging tool verifies the archive hash, safe layout and every internal
payload hash, and refuses collisions with existing network setup files.
The kit source/build tool is maintained in shinogi-emu/shinogi under
tools/make-tap-setup.py and tools/win; driver provenance, licenses, matching
driver source and the targeted installer source are included in the kit.
